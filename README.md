# Harry's GitHub Pages

Hi there! This is the repository for my [GitHub Pages site](https://harryplusplus.github.io).

## Development

1. Install [nvm](https://github.com/nvm-sh/nvm).

2. Install and use the Node.js version specified in `.nvmrc`.

   ```sh
   nvm install
   nvm use
   ```

3. Enable corepack.

   ```sh
   corepack enable
   ```

4. Install dependencies.

   ```sh
   pnpm i
   ```

5. Run the development server.

   ```sh
   pnpm dev
   ```
