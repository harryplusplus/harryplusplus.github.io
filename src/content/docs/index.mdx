## Senior Backend Engineer @ Corp X

_2021–2025 · Go, Kafka, Redis, Kubernetes_

### Problem

The tracing pipeline could only handle 2k spans/sec before falling over. P99 latency for critical API endpoints was 2.3s.

### Solution

Replaced the monolithic ingestion with a Kafka-backed streaming pipeline. Added a local LRU cache layer with write-behind persistence. Rewrote the hotpath in Go.

### Result

- Throughput increased to 10k spans/sec
- P99 latency reduced by 60% (2.3s → 920ms)
- Infrastructure cost cut by 40%
