# Career

**Backend Engineer** — 10+ years building distributed systems, data pipelines, and high-traffic services.

## Senior Backend Engineer @ Corp X

_2021–2025 · Go, Kafka, Redis, Kubernetes_

### Problem

The tracing pipeline could only handle 2k spans/sec before falling over. P99 latency for critical API endpoints was 2.3s.

### Solution

Replaced the monolithic ingestion with a Kafka-backed streaming pipeline. Added a local LRU cache layer with write-behind persistence. Rewrote the hotpath in Go.

### Result

- Throughput increased to 10k spans/sec
- P99 latency reduced by 60% (2.3s → 920ms)
- Infrastructure cost cut by 40%

### What I Learned

How to design backpressure-aware systems. The hard way.

**Stack:** Go, Kafka, Redis, OpenTelemetry, Kubernetes

## Backend Engineer @ Startup Y

_2018–2021 · Python, PostgreSQL, AWS_

### Problem

Customer analytics were T+1 delayed. Batch jobs that ran nightly kept failing mid-way with no observability.

### Solution

Built a real-time analytics pipeline (Kafka → Flink → ClickHouse). Replaced ad-hoc Python scripts with Airflow DAGs. Added data quality checks and alerting.

### Result

- Data freshness improved from T+1 to &lt;5 minutes
- Zero silent failures (alerts caught everything)
- Team of 3 adopted the pipeline for their own use cases

### What I Learned

Observability isn't a feature — it's a prerequisite.

**Stack:** Python, Kafka, Flink, ClickHouse, Airflow, AWS
